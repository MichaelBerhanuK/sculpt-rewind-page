Sculpt Rewind Documentation

Undo history for sculpting, masks, Face Sets and colors. Scrub back and forth through every change on a mesh, like a timeline.

Requires Blender 4.2 or newer

Install

  1. Go to Edit → Preferences → Get Extensions → Install from Disk.
  2. Pick the Sculpt Rewind .zip file.

Activating

  • History starts on an object's first stroke. Opening a file or switching modes records nothing.
  • Painting first in Vertex Paint mode also starts history.
  • Turn Off Undo History pauses recording and keeps the existing steps. Changes made while recording is off become the new starting point when you turn it back on.
  • Reset and Turn Off removes the history entirely and cannot be undone.

Getting Started

  1. Select a mesh and enter Sculpt Mode.
  2. Sculpt as usual. Each stroke is recorded as one step.
  3. The Undo History scrubber appears at the bottom of the 3D View. Drag along it to move through your history.

What Gets Recorded

Sculpt Rewind records sculpt strokes, masks, Face Sets, visibility, vertex colors, filters, and topology-changing tools such as Voxel Remesh and Trim. Filter adjustments made through F9 update the same step. Edit Mode changes are grouped into one step when you leave, including Shade Smooth or Flat; entering and leaving without changes records nothing.

Shortcuts

Step back
Ctrl+Z · Cmd+Z on Mac
Step forward
Ctrl+Shift+Z · Cmd+Shift+Z on Mac
Branching and truncation: If you step back and then sculpt, you start a new branch. The confirmation appears only when you would lose at least the Truncation Warning Threshold number of steps set in Add-on Preferences. Below that threshold, future steps are dropped silently. After confirming, repeat the stroke to continue.

History Menu

The dot next to the scrubber opens the History Menu.

  • Use Global / Active Object Undo History: Switch between one object's history and a single timeline for all objects.
  • Preserve Modes: Keep each object's mode when Global history switches objects.
  • Set Morph Target Here: Mark the current step as a target.
  • Morph History Brush: In Sculpt Mode, paint parts of the mesh back toward the target.
  • Delete Past Undo Steps: Remove older steps to free memory and reduce the size of the saved history. Later steps stay.
  • Reset Undo History: Clear this object's history. The current mesh becomes the new starting point.
  • Turn Off Undo History: Pause recording while keeping the existing steps.
  • Reset and Turn Off: Remove the history entirely and stop recording. This cannot be undone.
  • Turn On Undo History: Start recording again on an object where it was turned off.

Object and Global History

  • Alt+Q switches objects in Sculpt Mode, and each object keeps its own history.
  • Global History shows every object's steps on one timeline, in order.
  • With Preserve Modes off, Global History plays back the geometry without switching the active object or mode.

Morph History Brush

  1. Set a target from the History Menu with Set Morph Target Here.
  2. Pick the Morph History tool.
  3. Paint over the areas you want to move back toward the target.

Each Morph stroke is one normal undo step. Morph does not work with Shape Keys, Dyntopo or Multires.

Movie Mode

Play your whole sculpting session back as an animation—for example, to render a timelapse.

  1. Switch the History Menu to Use Global Undo History. Movie Mode only works with Global history.
  2. Open the sidebar with N, then go to Undo History → Movie Mode. Turn it on with the checkbox in the header.
  3. Click Quick Auto Key. This keys the first and last steps of your history on the Timeline.
  4. Press Play or scrub the Timeline to watch the session rebuild itself.

You can also keyframe the Step value yourself to set the timing. Frames per Step controls playback speed.

While Movie Mode is on, the history scrubber is locked and the Timeline drives playback. Movie Mode only plays history back—it never changes your history. Turning it off pauses playback, and your keyframes stay.

Sidebar

Open it with N, then choose the Undo History tab. From there you can:

  • Reset history for this object or for all objects
  • Use Movie Mode
  • Change how the scrubber looks
  • Set memory limits

Collection Filtering

Open Sidebar → Undo History → Collection Filtering.

  • Blacklist: Exclude selected collections.
  • Whitelist: Record only objects in selected collections.
  • Excluded objects record nothing and their existing history is hidden, not deleted. Moving them back into an included collection brings the history back.

Saving

Choose how history is stored in Add-on Preferences:

  • Sidecar: Stores a history folder beside the .blend file for the fastest saves.
  • Embed: Stores history inside the .blend, giving you one file to share.
  • Both: Keeps both forms of storage.

In Sidecar mode, keep the history folder next to the .blend and keep the matching name. If you rename or move the .blend without its history folder, you will see “Sculpt Undo History Not Found.”

To send someone a single file, switch to Embed and save.

Recovery after a crash

Last Saved is the safe default. Choose Interrupted Session to recover the unsaved steps from the interrupted session.

Unsupported / Warnings

  • Dyntopo and Multires: Not supported. A warning appears in the viewport.
  • Object transforms: Not recorded. Moving a sculpted object can make older steps play back in the wrong place.
  • Unsupported data: Modifiers, Shape Keys, Materials, Vertex Groups and Weight Paint are not stored. Deform modifiers such as Armature and Displace can produce unpredictable results.
  • Join (Ctrl+J): Sculpt Rewind asks first, then merges the histories into one.
  • Separate (P) / Mask Extract: Sculpt Rewind asks first. The new object starts its own history.
  • Linked Duplicate (Alt+D): A warning explains that the objects share mesh data. Use Shift+D for independent history.
  • Animated objects: Playback may differ from what was recorded.
  • Global Undo: Must be enabled under Preferences → System.
